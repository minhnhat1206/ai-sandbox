# AI Sandbox

**Try-before-you-buy environment for AI adoption.** Prospects open an invite link and run
workflows and chat agents that we built for their company, on our AI credits, with no
account and nothing to install. Every run is measured (minutes saved, rating) and ends
with a path to a sales call.

Built for the business in `docs/AI_Enablement_Business_Plan.md`; product design in
`docs/DESIGN.md` and the visual system (tokens, bespoke icon set, illustrations) in
`docs/DESIGN-SYSTEM.md` (Vietnamese).

## Quick start

```bash
npm install
npm run dev
```

- Prospect demo: http://localhost:3000/s/demo
- Admin console: http://localhost:3000/admin (password `change-me` until you set `ADMIN_TOKEN`)

Without any API key the platform runs in **demo mode** (mock provider): every screen and
flow works. Agent workflows still run the real tools (queries, aggregations, tickets,
artifacts) against the sample data; only the narration is scripted, and it is labelled.

## What prospects can try

- **Agents** that look up their data (CSV tables we connect, or real MCP servers with
  Claude), check company documents, open tickets, draft emails and publish deliverables:
  HTML dashboards, tables, CSV, markdown, and real `.xlsx` files through Agent Skills.
- **File inputs**: PDF, images, CSV and text (contract review, data clean-up).
- Full transparency: a timeline of every tool call, the artifacts, and the actions taken.

### Connect real Claude

```bash
cp .env.example .env
# set AI_PROVIDER=anthropic, ANTHROPIC_API_KEY=sk-ant-..., ADMIN_TOKEN=<strong secret>
npm run dev
```

Runs are then generated by `claude-opus-5-5` (configurable via `ANTHROPIC_MODEL`,
`ANTHROPIC_EFFORT`) and billed to your key. Server-side refusal fallbacks are enabled.

## Scripts

| Script | Purpose |
|---|---|
| `npm run dev` | Vite dev server with the API mounted |
| `npm run check` | typecheck, catalog validation, unit/API tests, build |
| `npm run smoke` | Playwright end-to-end test with screenshots (`e2e/screenshots/`) |
| `npm run build && npm start` | production server (serves `dist/` + API on `PORT`) |
| `npx tsx scripts/create-sandbox.ts payload.json` | create a prospect sandbox from JSON |

## Layout

```
shared/   types, workflow catalog, template engine, validators (browser + server)
server/   Hono API, runner, providers (mock | anthropic), JSON store
src/      React app: prospect sandbox (/s/:token), admin console (/admin), icons/, components/
tests/    vitest · e2e/smoke.mjs Playwright · scripts/ tooling
.claude/  rules, skills, subagents, hooks for working on this repo with Claude Code
data/     db.json (gitignored) – prospect sandboxes, runs, leads
```

## Working with Claude Code

Skills: `/new-workflow`, `/new-sandbox`, `/demo-script`, `/tune-prompt`, `/release-check`.
Rules in `.claude/rules` load automatically; hooks block reading `.env`, hand-editing
`data/db.json`, and force-pushing `main`, and run typecheck/catalog validation after edits.

## Deploy

Any Node 22 host: `npm ci && npm run build && npm start`, persist the `data/` directory,
set `ADMIN_TOKEN`, `AI_PROVIDER=anthropic`, `ANTHROPIC_API_KEY`, `VITE_BRAND_NAME`
(build-time) and `PORT`.
