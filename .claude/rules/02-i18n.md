# Bilingual rule (VI + EN)

- All UI text goes through `src/i18n/dict.ts` as `{ vi, en }` and is used with
  `t('key')` from `useLang()`. Never hard-code a Vietnamese or English sentence in JSX.
- Bilingual domain fields (`name`, `tagline`, `description`, `label`, `title`,
  `greeting`, `starters`) use the `L` type and are rendered with `pick(l)`.
- Prompts to the model are written in **English** (more reliable instruction
  following) and tell the model to answer in `{{language}}`. Sample inputs are in
  **Vietnamese** unless the workflow is specifically for English content.
- Vietnamese copy: polite, plain, no jargon. Address the reader as "bạn". Avoid
  literal translations from English; write the way an operations manager in HCMC would.
- When adding a dictionary key, the post-edit hook checks both languages exist.
